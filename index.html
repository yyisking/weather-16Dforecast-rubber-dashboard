指数计算逻辑（大白话说明 · 点击展开）

一句话：先在每个监测点上用"它自己的历史同期"判断天气坏不坏，再按产量权重加总——不让大产区的好天气掩盖小产区的坏天气（先判后权）。

1. 分级（0–3 级）：每个点、每个指标，与自身 2005 年（小时类 2015 年）以来的同期比较：向有害方向偏离不到 0.5 个标准差算 0 级（无害），≥0.5σ 轻度(1级)、≥1σ 中度(2级)、≥2σ 重度(3级)。往好的方向偏不算分。

2. 两层分数：割胶层管当期产量（清晨雨日权重 0.7 + 清晨雨量 0.3）——清晨下雨当天就没法割；树况层管潜在产能（土壤湿度 0.30、夜温 0.25、空气干燥度 0.20、高温 0.15、雨量 0.10）——树受伤了几个季度都缓不过来。每层各算 0–100 分。

3. 累积效应：连续清晨雨、土壤连续亏缺天数、35℃ 以上的热量积累，比单日波动更伤——这些累积特征单独分级，并把对应指标的级别往上抬。

4. 干热叠加：空气干燥(VPD)和土壤缺水同时达到中度以上时，树况分额外 +10%——又干又热不是简单的 1+1。

5. 割季门控：越冬停割期（如云南 12–2 月）清晨雨再多也不构成当期损失，割胶分乘以逐月割季系数（停割期≈0）。树况分不乘——树在冬天照样会受伤。

6. 汇总与三个核心数：产区内按点的产量权重、全球按产区产量份额加权。每个产区/全球看三个数：割胶受胁占比（多少产量当期割不动）、树况受胁占比（多少产量树况受损）、胁迫指数（0.4×割胶分+0.6×树况分，综合深度）。受胁线 = 分数 ≥25（约达 1 级）。

7. 格局标签：深度(指数)×广度(树况占比)四象限：指数高但只有少数点受损=点状冲击；指数中等但普遍承压=面状承压；又高又广=广泛受损；双低=基本正常；其余=局部承压。层级：L1 扰动(只有割胶受扰) → L2 损失(割胶持续受胁或树况达轻度) → L3 损伤(土壤亏缺/热积累等累积特征达中度以上，威胁跨季产能)。

8. 方向：与上一个 30 天窗口用同一套方法重算比较，变化超过 5 分记上升/下降，否则持平。

所有阈值与权重集中在 impact_config.json，标注"待校准"的参数为保守初值，将在阶段 3 用历史产量数据校准。

数据来源

  • 气象数据：Open-Meteo 开源气象 API
    • 历史实况：ERA5 再分析数据（欧洲中期天气预报中心 ECMWF），日值 2001 年起、逐小时 2015 年起；归档约有 5 天延迟
    • 近端缺口与预报：Open-Meteo Forecast API（ECMWF IFS / GFS 等混合模式），近 40 天回填 + 未来 16 天预报
  • 监测要素：日最高/最低气温、降水、根区土壤湿度、VPD 空气干燥度（由温湿度导出）、清晨降雨（03–09 时）
  • 监测点：38 个气象点 / 10 个产区（泰国、印尼、越南、科特迪瓦、中国云南、马来西亚、中国海南、柬埔寨、缅甸、老挝），覆盖全球天然橡胶产量约 78%
  • 产量权重：基于 ANRPC 及公开资料的各产区产量占比估计（近似值，随年度产量变化，定期校准）
  • 更新频率：每日 08:27（北京时间）自动更新；数据窗口为滚动 30 天

计算逻辑（简版）

  1. 先判后权：每个监测点用自身历史同期气候基准计算距平，按偏离程度分 0–3 级（0.5σ / 1σ / 2σ），在点级完成影响判定后再按产量权重汇总
  2. 双层评估：割胶层（当期供应）= 清晨雨日 ×0.7 + 降水量 ×0.3，乘以割季门控系数；树况层（潜在产能）= 土壤湿度 ×0.30 + 夜温 ×0.25 + VPD ×0.20 + 高温 ×0.15 + 雨量 ×0.10
  3. 非线性处理：连续清晨雨天数、土壤亏缺累积日、热积累等累积特征达到阈值会提升胁迫级别；VPD 与土壤湿度同时重度异常时叠加交互加成
  4. 供应天气胁迫指数（0–100） = 割胶分 ×0.4 + 树况分 ×0.6；受胁占比 = 胁迫分 ≥25 的监测点的产量权重占比
  5. 格局标签：指数（深度）× 受胁占比（广度）四象限 → 点状冲击 / 面状承压 / 广泛受损 / 基本正常
  6. 层级：L0 平稳 / L1 扰动（日级可恢复）/ L2 损失（月级缺口）/ L3 损伤（跨季产能风险），由累积量自动升级
  7. 方向：与上一 30 天窗口比较的指数变化（±5 以内为持平）
